# Prozone.shop — Starter Website

Static frontend for a digital-products store.

## Included
- Responsive dark/purple storefront
- Product categories and search
- Cart UI
- Crypto checkout UI with ONLY BTC and LTC
- Placeholder wallet addresses

## Important
This is a frontend demo. Before accepting real crypto payments, replace the configured BTC and LTC wallet addresses and connect a reputable payment processor or build a secure server-side payment verification flow. Do not rely on browser-only payment confirmation.

## Files
- index.html
- style.css
- script.js


Updated: login/register gate appears first for new visitors; BTC/LTC QR codes are included in checkout. Payment remains demo-only and requires server-side verification before accepting real orders.
